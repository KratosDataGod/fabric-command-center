# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be kind, assume good intent, and keep discussion about the work. Report unacceptable behaviour to the maintainers through GitHub (open a private security report if it needs to stay confidential). Maintainers will review every report and respond as fairly and quickly as they can.
